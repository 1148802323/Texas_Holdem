# 网页牌桌（本地运行）

本阶段提供管理员管理页、邀请入座页、牌桌、个人记录、HTTP 接口和 WebSocket 实时同步。使用 FastAPI、Uvicorn 与浏览器原生 JavaScript；后端仍采用现有 SQLite 数据库与游戏引擎。

## 启动

在项目根目录，用项目 Conda 解释器安装依赖：

```powershell
D:\miniconda\envs\Texas_Holdem\python.exe -m pip install -r backend/requirements.txt
```

在**当前 PowerShell 窗口**设置至少 12 位、只有你知道的管理员密码，并启动本地服务：

```powershell
$env:TEXAS_ADMIN_PASSWORD = '请替换成你自己的至少十二位强密码'
D:\miniconda\envs\Texas_Holdem\python.exe -m uvicorn backend.app.api.server:create_app --factory --host 127.0.0.1 --port 8000
```

然后访问 `http://127.0.0.1:8000/admin`。管理员创建房间后，页面会给出 `/r/<room_id>` 邀请链接。玩家无需账号，先选择昵称进入旁观区，再点击空座位上的加号入座。浏览器用 `HttpOnly` Cookie 保存房间身份。刷新页面后再次请求最新状态，并重新连接 WebSocket。

默认数据库在 `database/texas_holdem.sqlite3`，可通过 `TEXAS_DB_PATH` 指向别的文件。升级已有环境时，应先停服，再将 `database/holdem.sqlite3` 改名为 `database/texas_holdem.sqlite3`；已经通过 `TEXAS_DB_PATH` 指定路径的环境无需改名。数据库文件包含未公开底牌，不应放到公开的静态文件目录。服务器部署的路径和备份方法见 [部署与备份准备](deployment.md)。

## 当前流程

1. 管理员登录、创建房间，设置大小盲、人数、买入上限、各阶段与全下发牌投票时限，以及昵称规则。默认时限依次为翻前 60 秒、翻牌 60 秒、转牌 120 秒、河牌 180 秒、投票 60 秒。管理列表中的“复制邀请链接”只复制地址，不会离开管理页。
2. 把邀请链接发给朋友。玩家可先旁观；入座后在两手牌之间自行买入。同一有效昵称和座位不能重复占用。站起后筹码留在该昵称下，换座不会重置筹码。
3. 入座并买入后勾选准备。满桌时全员准备自动开局；未满桌时全体入座玩家还需分别确认“现在开局”。准备状态跨手牌保留，结算后约 4 秒自动开始下一手；少于两名已准备且有筹码的玩家时停止。开局后座位不再显示“已准备”。首手庄位随机抽取，后续按实体座位轮转；庄家 D 按钮显示在对应座位框外、朝向桌心的一侧。每位已入座玩家看到的牌桌都会旋转，使自己的座位始终在下方，实体座位和行动顺序不变。
4. 每次操作后，服务端分别给各玩家推送其有权看到的牌局状态；未公开底牌不会发送给其他玩家。
5. 宽屏牌桌左侧显示按已结算筹码计算的昵称盈亏，右侧可按手牌编号或牌面查找自己的记录；较窄屏幕可通过牌桌上方的左右按钮打开对应侧栏。每位玩家本轮已投入的筹码以筹码图标和数字单独显示在该座位框前。正在参与本手的玩家不能换座、站起或退出；未参与本手的旁观者可以入座，等待下一手。
6. 倒计时秒数与百分比对全桌公开。当前行动玩家在最后 5 秒可以单次延时，增加该阶段的完整时限。超时能过牌则过牌，否则弃牌。全下且后续无人能下注时，入池玩家投票发一次或两次；超时视为一次。每个底池按有资格争夺该池的玩家分别决定，发两次的底池均分后分别判牌（奇数筹码给第一次）。
7. 管理员只能在玩家行动或全下投票决策期间暂停；恢复时继续同一决策的剩余时间。退出牌桌会注销当前身份，将剩余筹码记录为离桌兑出并清除浏览器令牌。
8. 行动者座位会亮起，行动按钮和公开倒计时直接显示在牌桌下沿。新手或下一条街发牌时有约 1 秒过渡，决策倒计时从过渡结束后完整计算；状态更新不会重新闪烁已展示的牌。点击“开启声音”后，轮到自己行动会播放提示音，动作会随机播放对应类别音效，发牌可使用 `deal` 音效。音频放入 `frontend/src/audio/`，按其中说明命名；没有提示音文件时会生成短提示音。
9. 管理员可以删除牌桌：房间从管理列表移除、邀请停止接收新玩家，数据库中的买入与手牌记录保留。若删除时有手牌正在进行，它仍可完成结算，之后不会自动开始下一手。原玩家凭证仍可查看自己的历史。
10. 玩家凭证使用有效期 30 天的持久 Cookie；在同一浏览器、同一域名下普通关闭并重新打开浏览器，会自动恢复原身份。换设备、切换浏览器、使用隐私模式或清除 Cookie 后，向房主索取一次性恢复码，在邀请页“恢复原来的玩家身份”中输入。恢复码有效期 15 分钟，只能使用一次；恢复后原设备会失去访问权，新设备保留原座位、筹码、历史及当前手牌，不重置倒计时。管理员重新生成恢复码会使旧码失效。
11. 管理页显示玩家在线状态，并可强制离座或移出。强制离座释放座位但保留筹码和身份；移出会将结算后剩余筹码计入离桌兑出并使其凭证失效。参与当前手牌时管理操作在本手结算后执行，管理页可查看最近操作记录。

## 权限与运行边界

- 管理员密码由环境变量提供；服务未配置密码时拒绝启动。管理员会话在进程内保存 12 小时，重启后重新登录。
- 房间链接使用随机房间 ID；知道链接的人可以尝试加入空座位。昵称不是身份证明，已加入玩家使用 30 天有效的持久 Cookie 令牌恢复身份；主动退出会清除令牌。
- WebSocket 同样检查玩家 Cookie，并逐个生成私人视图；跨来源浏览器请求被拒绝。
- 当前实时连接管理位于单个服务进程内。启动 Uvicorn 时使用一个 worker；未来多实例部署需要共享消息系统。
- 手机端牌桌采用纵向椭圆；常见手机尺寸下底牌和行动按钮可在同一屏查看，极矮屏幕允许纵向滚动以避免遮挡。盈亏从左侧栏打开，个人记录从右侧栏打开；关闭按钮、背景或 Escape 键可收起侧栏。
- 本页的本地启动命令只在本机开放；线上服务使用 HTTPS/WSS、Caddy 和定时备份，详见[部署指南](deployment.md)。
- 在线状态根据当前 WebSocket 连接判断，连接中断后管理页会显示离线。恢复码应由管理员私下交给对应玩家；获得该码的人能接管该玩家身份。
- 买入审批尚未实现；从旧版启动时，数据库自动迁移到 v4 结构。重启已有的服务进程后才会执行迁移。升级前可先备份 `database/texas_holdem.sqlite3`。
